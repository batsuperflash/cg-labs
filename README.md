# Компьютерная графика: лабораторные работы на Vulkan

Код основан на [стартовом проекте](https://github.com/vladeemerr/vulkan-starter-app) преподавателя: GLFW, vk-bootstrap, Vulkan Memory Allocator и Dear ImGui. Каждая работа лежит в своей папке и собирается отдельно: `cmake --preset debug` и `cmake --build build-debug` из папки работы.
