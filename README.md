# Компьютерная графика: лабораторные работы на Vulkan

Код основан на [стартовом проекте](https://github.com/vladeemerr/vulkan-starter-app) преподавателя: GLFW, vk-bootstrap, Vulkan Memory Allocator и Dear ImGui.

## Лабораторная работа №1. Основы 3D-графики

**Вариант 10 — правильный додекаэдр.**

Построить правильный додекаэдр, спроецировать его на плоскость экрана и отрисовывать в реальном времени с помощью Vulkan. Проекцию и трансформации объекта можно менять во время работы программы.

| Задание | Статус |
|---|---|
| Основное: правильный додекаэдр в перспективной проекции | ✅ |
| 1. Переключение ортографической и перспективной проекции | ✅ |
| 2. Позиция, поворот и масштаб фигуры в интерфейсе | ✅ |
| 3. Движение и вращение по сложной траектории, пауза, скорость и параметры траектории | ✅ |
| 4. Цвет фигуры в интерфейсе | ✅ |
| 5. Процедурные цвета вершин, умножаемые на цвет из интерфейса | ✅ |
| 6. Несколько объектов, у каждого свой набор дескрипторов | ✅ |

### Как устроено

- **Додекаэдр** строится в коде ([geometry.cpp](source/geometry.cpp)). Вершины: (±1, ±1, ±1), (0, ±1/φ, ±φ), (±1/φ, ±φ, 0), (±φ, 0, ±1/φ), где φ — золотое сечение. Нормали 12 граней направлены на вершины двойственного икосаэдра: для каждой нормали берутся 5 самых удалённых вдоль неё вершин и упорядочиваются по углу. Каждый пятиугольник разбит на 3 треугольника: всего 36 треугольников и 108 индексов.
- **Матрицы** переноса, поворота, масштаба, вида и проекций написаны вручную ([transform.cpp](source/transform.cpp)) под соглашения Vulkan: ось Y в clip space направлена вниз, глубина лежит в [0, 1].
- **Сцена** ([scene.cpp](source/scene.cpp)) хранит камеру и объекты и считает матрицы. Матрица модели: `T(точка траектории + позиция) · R(собственное вращение) · Rz · Ry · Rx · S`, то есть сначала масштаб, потом поворот и перенос.
- **Ортографическая проекция** видит ту же высоту `2 · d · tan(FOV / 2)`, что и перспективная в плоскости z = 0, поэтому при переключении размер фигуры в центре сцены не меняется.
- **Траектория** — трёхмерная фигура Лиссажу `p(t) = R · (sin(a·t + δ), sin(b·t), sin(c·t))`. Время анимации накапливается по кадрам, поэтому пауза и смена скорости не вызывают скачков.
- **Цвет вершины** вычисляется из её положения: `position · 0.5 + 0.5`. Итоговый цвет — цвет вершины, умноженный на цвет из интерфейса.
- **Несколько объектов** (до 8): у каждого свой uniform buffer с матрицами model, view, proj и цветом и свой descriptor set, который на него ссылается. Перед отрисовкой объекта привязывается его набор. Один общий буфер не подошёл бы: команды выполняются на GPU уже после записи командного буфера, и все объекты получили бы данные, записанные последними. Буферы и наборы создаются при запуске сразу для всех восьми объектов, поэтому во время работы ничего не создаётся и не удаляется.

### Сборка

Нужны компилятор C++20, CMake 3.20+, Ninja и Vulkan SDK (в нём есть компилятор шейдеров `glslc`). Остальные зависимости CMake скачивает сам.

- **macOS:** установить [Vulkan SDK](https://vulkan.lunarg.com/sdk/home) с компонентом *System Global Installation* и Ninja (`brew install ninja`).
- **Linux, Windows:** см. раздел Getting started в [README стартового проекта](https://github.com/vladeemerr/vulkan-starter-app#getting-started).

```bash
cmake --preset debug
cmake --build build-debug
```

### Запуск

Из корня репозитория, иначе программа не найдёт шейдеры:

```bash
./build-debug/vulkan-starter-app
```

### Управление

Окно **Lab 1** в левом верхнем углу. Разделы Transform, Animation и Color относятся к выбранному объекту:

| Раздел | Что можно менять |
|---|---|
| Camera & projection | Перспективная или ортографическая проекция, угол обзора, расстояние до камеры, ближняя и дальняя плоскости |
| Objects | Выбор объекта, Add добавляет объект (до 8), Remove удаляет выбранный |
| Transform | Позиция, поворот в градусах и масштаб по осям; Reset transform возвращает исходные значения |
| Animation | Пауза и запуск, сброс, скорость движения и собственного вращения, радиус, частоты и сдвиг фазы траектории |
| Color | Цвет фигуры и включение процедурных цветов вершин |

### Тесты

```bash
./build-debug/lab_tests
```

Тесты не открывают окно и не используют Vulkan. Они сверяют матрицы с GLM и проверяют:
- геометрию додекаэдра: 20 вершин на единичной сфере, 30 рёбер одной длины, 12 граней, V − E + F = 2, замкнутость поверхности и обход треугольников против часовой стрелки снаружи;
- порядок преобразований в матрице модели и одинаковый размер сцены в обеих проекциях;
- траекторию, шаг анимации и паузу;
- цвета вершин;
- добавление и удаление объектов.
