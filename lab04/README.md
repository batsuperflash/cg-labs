# Лабораторная работа № 4. Карты теней

**Вариант 10 — правильный додекаэдр.** На полу видны тени движущихся фигур. Для солнца и первого прожектора программа каждый кадр строит отдельные карты глубины 1024 × 1024.

[Отчёт по лабораторной работе (PDF)](reports/309_Тарабрина_Лаб4.pdf)

## Запуск на этом Mac

Дважды нажмите `Run.command` в Finder. Скрипт запускает локальную сборку из каталога с текстурами и шейдерами. После клонирования с GitHub при первом запуске он собирает программу по инструкции ниже. Из Терминала в этом каталоге выполните `./Run.command`.

## Что показать

1. Откройте раздел **Shadows**. Снимите и верните **Sun shadows**. При выключении пропадает тень от солнца, сам источник продолжает освещать сцену.
2. Для отдельного показа прожектора раскройте **Ambient & directional light** и снимите **Directional light**. В **Shadows** переключите **First spotlight shadows**. Смотрите на участок пола внутри светового пятна. В разделе **Spot lights** можно передвинуть первый прожектор и изменить направление его луча.
3. Верните **Directional light**. Ползунок **Sun coverage width** задаёт длину стороны квадратной области, охваченной солнечной картой. При меньшем охвате внутри области больше деталей. За её границей солнечная тень исчезает.
4. **Depth bias** сдвигает глубину при записи карт. При слишком малом значении на освещённых поверхностях может появляться ложная тень; чрезмерный сдвиг отделяет тень от фигуры. Начальное значение — 1,5.

## Основной код

- `source/shadows.cpp` — выделение двух depth-текстур, сэмплер со сравнением LESS, переходы layout, начало и конец динамического рендеринга.
- `source/graphics.cpp` — создание конвейера записи глубины с VkPipelineRenderingCreateInfo и единственной вершинной стадией.
- `source/application.cpp` — матрицы источников, заполнение обеих карт перед основным проходом, привязка карт к набору дескрипторов сцены. Солнце использует ортографическую проекцию, прожектор — перспективную с полным углом обзора, равным удвоенному внешнему углу конуса.
- `shaders/shadow.vert` — перевод вершины в пространство источника света.
- `shaders/mesh.frag` — sampler2DShadow и усреднение девяти сравнений глубины. Видимость ослабляет вклад соответствующего источника. Фоновый свет и свечение материалов сохраняются.
- `source/ui.cpp` — панель Shadows.

## Сборка из исходников

Требуются CMake, Ninja, компилятор C++20 и Vulkan SDK с glslc. При первом конфигурировании CMake загружает зависимости. Приложение использует Vulkan 1.3 с dynamicRendering.

```sh
cmake --preset debug
cmake --build build-debug
./build-debug/lab_tests
./build-debug/vulkan-starter-app
```
